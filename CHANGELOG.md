# Changelog

## 0.5 family — 2026-11-19

### Upgrading

Use the [family update guide](docs/updating.md) to plan the Crocodile and
Pirates maintenance window, the 0.4.21 site adoption and the service roles
migration. Check existing approval files for the 24-character minimum.
Review protected service and tunnel ports before resuming Pond and Pirate
work. The Windows guide covers the recovery copy and the published 0.2.10
legacy upgrade.

### Changes

- Install and sharing guides explain how Crocodile owns service roles and
  Pirate admission, and which plans need operator review.
- The trust guide explains approval links, protected listeners and secret
  handling. The site diagrams follow the current ownership boundaries.
- The Linux release examples and docs checks follow the 0.5 family set.
